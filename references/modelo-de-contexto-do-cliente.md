# Modelo privado de contexto por cliente
Este arquivo é apenas um modelo sem dados reais. Salvar informações corporativas em ambiente privado, separado da skill pública.
Campos: identificação da operação, unidades, áreas, equipamentos, centros de custo, definições de KPIs, metas, política de turnos, fuso, moedas, fontes autorizadas, frequência, hierarquia de aprovação, calendário e exceções.
Para cada fonte: sistema, nome da tabela/aba, dono, atualização, campo-chave e escopo permitido. Documente regras de competência e data operacional.
Não publique credenciais, dados de clientes, nomes ou processos internos neste repositório. Contexto não pode ser reutilizado entre tenants.
